# Contributing

## Setup

```bash
git clone https://github.com/bshepp-projects/project-tracker.git
cd project-tracker/server
npm install
npm start
# Open project-tracker.html in browser
```

## Making Changes

- Frontend: Edit the HTML files directly (CSS and JS are embedded)
- Backend: Edit `server/server.js`
- Test by refreshing your browser

## Pull Requests

1. Fork and clone
2. Create a branch (`git checkout -b fix-something`)
3. Make changes
4. Test in at least one browser
5. Push and open a PR

## Code Style

- 2-space indentation
- camelCase for JS, kebab-case for CSS classes
- No build process, just edit files directly

## Questions

Open an issue.
